# AI Disclosure Statement

## Purpose of AI Use

Artificial intelligence (AI) tools were used during the development of this software project exclusively as programming assistants.

The overall architecture, application design, implementation strategy, and project structure were conceived and implemented by the author. AI assistance was limited to supporting software development tasks, including:

- expanding manually written code into complete function implementations,
- improving code syntax, readability, and consistency,
- suggesting alternative implementations for existing solutions,
- identifying and correcting programming errors,
- explaining programming concepts and debugging issues.

The AI system used was **GPT-5.5** developed by **OpenAI**.

AI was not used to generate the project's research objectives, scientific methodology, experimental design, analysis, conclusions, or interpretation of results.
